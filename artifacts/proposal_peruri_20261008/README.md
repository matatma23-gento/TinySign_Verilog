# Paket proposal PERURI PURI-Sign

`Proposal_PERURI_PURI_Sign_final.docx` adalah salinan final dengan enam halaman utama, referensi, dan lampiran. Gambar timing utama tertanam pada halaman kinerja; dua gambar timing detail berada pada lampiran.

Validasi lokal menggunakan LibreOffice menghasilkan 11 halaman total: halaman 1–6 adalah isi utama, halaman 7–9 referensi/lampiran template, dan halaman 10–11 lampiran timing. Dokumen sumber template disimpan terpisah pada `source/` dan tidak ditimpa.

`Proposal_PERURI_PURI_Sign_sanitized.docx` adalah varian untuk impor Google Docs setelah login. File `.pdf` pada `qa/final_package/` adalah hasil render QA. `artifact.md` mencatat kontrak template dan batas klaim.

Google Docs sempat diperbarui untuk teks utama, referensi tambahan, dan keterangan luaran. Unggah gambar langsung ke sesi Google Docs belum dapat diselesaikan karena sesi browser masih berada di halaman login dan unggah gambar ditolak sebelum autentikasi. Salinan DOCX final lokal sudah memuat ketiga gambar timing.
