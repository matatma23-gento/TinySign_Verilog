2. Analisis Kenapa RAM Blocks & DSP Bernilai 0%

Dalam perancangan sirkuit terintegrasi untuk keamanan tinggi (Hardware Security Module), nilai 0% pada RAM dan DSP merupakan ciri arsitektur yang disengaja (Security-by-Design):

  • Isolasi Register Murni (Zero Block RAM): Data sensitif seperti Private Key, Digest, dan register sementara tidak menggunakan Block RAM bersama agar terhindar dari kebocoran data sisa (memory remnant) dan memudahkan penghapusan instan 1 siklus clock (Zeroization).
  • Konstruksi Arithmetic Berbasis Logika (Zero DSP): Pengali 256-bit diimplementasikan dengan algoritma modular shift-and-add di gerbang logika murni untuk menjamin eksekusi waktu konstan (Constant-Time Execution) guna mencegah Timing & Power Side-Channel Attacks.

3. Fitur Keamanan yang Terbukti dalam RTL

  • ECDSA secp256r1 (NIST P-256): Operasi kurva eliptik pada koordinat Proyektif Jacobian dengan algoritma inversi modular Fermat.
  • Deterministik Nonce RFC 6979: Pembangkitan nonce $k$ deterministik berbasis HMAC-SHA256 untuk memitigasi kerentanan TRNG yang buruk.
  • Hardware Key Vault & Read Isolation: Private key hanya dapat ditulis pada status unlocked dan tidak memiliki jalur pembacaan (No Read Path) ke bus luar.
  • Instant Anti-Tamper Zeroization: Penghapusan seluruh register rahasia secara simultan menjadi 0x0 dalam 1 siklus clock jika terdeteksi anomali.
